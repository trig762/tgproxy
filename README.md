# Автоматическая установка Telegram WEB Proxy на Ubuntu 26.04

Скрипт `install-tproxy-ubuntu-26.04.sh` предназначен только для чистого VPS Ubuntu 26.04 LTS `x86_64`. Он откажется запускаться, если обнаружит существующие каталоги Caddy, MTProxy, tproxy-server или пользовательскую конфигурацию Fail2ban.

## Что устанавливается

- закреплённый `telegramdesktop/tproxy-server`;
- официальный MTProxy;
- Caddy и сертификат Let's Encrypt;
- встроенный сайт IRON FORM;
- UFW: разрешены SSH, TCP 80 и TCP 443;
- Fail2ban: 5 ошибок за 10 минут приводят к блокировке на 90 часов;
- ежедневное обновление конфигурации MTProxy.

## Запуск

Загрузите файл на сервер, затем выполните:

```bash
chmod 700 install-tproxy-ubuntu-26.04.sh
sudo ./install-tproxy-ubuntu-26.04.sh \
  --domain proxy.example.com \
  --email admin@example.com \
  --ssh-port 22
```

Секрет генерируется автоматически. Не используйте `--secret`, если автоматизации не требуется: значение аргумента временно видно в списке процессов и сохраняется в истории команд.

После установки данные подключения доступны только root:

```bash
sudo cat /root/tproxy-connection.txt
```

## Перед запуском

DNS `A` домена должен указывать на IPv4 сервера. В firewall хостинга разрешите TCP 22 (или ваш SSH-порт), 80 и 443. Не открывайте 2398, 8888, 8080 и 8081.

Скрипт не предназначен для повторного запуска поверх готовой установки и не является деинсталлятором.
